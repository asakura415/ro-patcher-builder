📖 USER GUIDE & MANUAL

คู่มือและรายละเอียดฟังก์ชัน Modern RO Patcher Builder

🚀 1. ภาพรวมของระบบ (System Overview)

Modern RO Patcher Builder คือเครื่องมือสร้างและจัดการโปรแกรม Client Patcher ยุคใหม่สำหรับ Ragnarok Online พัฒนาด้วย Rust 2021 + Microsoft Edge WebView2

✔ ไม่ติด Anti-Virus (No False Positives) ✔ Single Executable (ไม่มี DLL ภายนอก) ✔ Multi-stream Download สูงสุด 32 เธรด ✔ In-Place GRF Merging รวดเร็ว ปลอดภัย ✔ Binary Overlay Engine (ROPATCH1)

📋 2. ขั้นตอนการใช้งานทีละ Step

1

Server & Mirrors (ตั้งค่าเซิร์ฟเวอร์แพตช์)

ระบุ URL ของไฟล์รายการแพตช์ plist.txt และโฟลเดอร์เก็บไฟล์ .thor สามารถเพิ่ม Mirror Servers ได้ไม่จำกัด หากเซิร์ฟเวอร์หลักล่ม Patcher จะสลับไปโหลดจาก Mirror อัตโนมัติ

2

Game & GRF (ตั้งค่าตัวเกมและไฟล์ GRF)

ระบุชื่อไฟล์เกม (เช่น _PRONTERA BOX.exe), Arguments (เช่น -1rag1), ตัวตั้งค่ากราฟิก (เช่น _PRONTERA BOX - Settings.exe) และชื่อไฟล์ GRF หลัก พร้อมตั้งค่าความเร็วเธรดดาวน์โหลด (1–32 streams)

3

UI Theme & Window (ปรับแต่งหน้าตา Patcher)

เลือกขนาดหน้าต่าง (กว้าง x สูง), ความโปร่งแสง (Transparent Frameless), เลือกไฟล์ไอคอนเกม .ico และเลือกโฟลเดอร์ธีม Web UI (HTML/CSS) ตามต้องการ

4

Patch Maker (เครื่องมือสร้างไฟล์แพตช์ .thor)

นำไฟล์เกมใหม่ ๆ เช่น data/ วางในโฟลเดอร์ต้นทาง จากนั้นกดสร้างไฟล์ .thor พร้อมตั้งค่าให้เขียนทับไฟล์ plist.txt รันเลข Patch Index ให้อัตโนมัติ

5

Generate Patcher (ส่งออกไฟล์ Patcher ตัวจริง)

กดปุ่ม GENERATE STANDALONE PATCHER ระบบจะนำ Config, Icon และ UI Theme ผสานเป็นไฟล์ .exe ตัวเดียวพร้อมแจกจ่ายให้ผู้เล่นได้ทันที!

💡 3. ฟังก์ชันและเทคนิคพิเศษ

  • Auto-Scan Game Folder: ปุ่มลัดสีเขียวที่แถบเมนูด้านซ้าย ช่วยสแกนค้นหา Executable, Settings, และไฟล์ GRF ในโฟลเดอร์เกมให้อัตโนมัติในคลิกเดียว
  • Light / Dark Mode: กดปุ่มสลับธีมที่มุมบนขวา เพื่อเลือกโทนสีตามความสบายตา (บันทึกจำค่าอัตโนมัติ)
  • Self-Update Support: เมื่อสร้างแพตช์ที่มีไฟล์ Patcher ตัวใหม่ ตัว Patcher ของผู้เล่นจะอัปเดตตัวเองอัตโนมัติโดยไม่ต้องให้ผู้เล่นดาวน์โหลดใหม่
